# Idea Shelf

アカウント登録なしで使える、URLベースのアイデア共有ボードのフロントエンドプロトタイプです。

## 起動

静的ファイルを配信できる任意のHTTPサーバーで起動します。

```powershell
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。

## 実装済み

- 階層フォルダの作成、名前変更、削除
- Markdown入力とプレビュー
- タイトルの本文先頭行からの自動生成
- カード形式の一覧
- 更新日、作成日、手動ドラッグによる並び替え
- 明示的な保存操作
- 編集用URLと閲覧専用URL
- フォルダ単位の公開・非公開
- Local Storageによる最近のボード
- PC / モバイルのレスポンシブ表示

## 現時点のデータ保存について

この版はバックエンドを持たず、データをブラウザのLocal Storageに保存します。そのため、共有URLは同じブラウザ環境でのみデータを参照できます。端末をまたぐ実運用には、データベースとサーバー側のURLトークン認証を追加してください。
